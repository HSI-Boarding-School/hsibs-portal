# 🚀 Quick Start - Link Management

## Akses Aplikasi

### Dari Sidebar
1. Buka dashboard
2. Klik **"Link Management"** di sidebar
3. Pilih **"Home"** atau **"Portal"**

### Direct URL
- **Home**: `http://localhost:3000/dashboard/link-home`
- **Portal**: `http://localhost:3000/dashboard/link-management`
- **Public**: `http://localhost:3000/links/azmanzakki`

### Link Management Portal
- **Add Link**: Klik tombol biru "Add Link"

- **Delete Link**: Klik icon trash di tabel

### Public View

## 🎯 Cara Menggunakan

### Tambah Link
```
1. Buka Portal
2. Klik "Add Link"
3. Isi form:
   - Nama Link: "Instagram"
   - URL: "https://instagram.com"
   - Thumbnail: "/assets/icons/platforms/ic_instagram.svg"
4. Klik "Tambah"
```

### Edit Link
```
1. Di tabel, klik icon pen
2. Ubah data
3. Klik "Update"
```

### Hapus Link
```
1. Di tabel, klik icon trash
2. Konfirmasi penghapusan
```
